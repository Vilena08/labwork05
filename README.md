# Лабораторная работа: Решение задач на C#

## Автор
Сайбуу Вилена 

## Цель
Освоение базового синтаксиса C# и алгоритмического мышления на примере решения двух задач: возведение в степень без использования готовых функций и перестановка цифр числа.

## Описание
Программа создает словарь часто встречающихся ошибочных слов, затем обходит все текстовые файлы в указанной директории, исправляет в них ошибки и заменяет номера телефонов из формата (012) 345-67-89 на +380 12 345 67 89.

## Ожидаемый результат
Программа выводит список обработанных файлов, количество исправлений и замен в каждом файле, а также итоговый отчет.
